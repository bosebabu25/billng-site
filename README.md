# billng-site

1. Open Preview, then Print
  On the billing page, click "Preview Bill", check the receipt looks right, then click the 🖨 Print button inside the preview (not your browser's own print shortcut) — this also saves the sale to your log before opening the print dialog.

3. Set Margins to "None"
  In the print dialog that opens, find the Margins dropdown and set it to "None". The default browser margins were the main reason the receipt was spilling onto a second page.

4. Turn off Headers and Footers
  Click "More settings" in the print dialog and uncheck "Headers and footers". This removes the URL, date, and title text the browser was adding at the top and bottom of the page.

5. Pick the right paper size
  If you're printing on a normal printer, keep A4 or Letter — with margins removed it will now fit on one page. If you have a thermal/receipt printer (like a POS roll printer), instead choose that printer as the destination and select its roll width (e.g. 80mm) as the paper size — the receipt is narrow by design and will print like a real till receipt.

6. Check the print preview
  Before clicking the final Print button, glance at the preview panel in the dialog — it should now show just one page with everything from the logo down to "Thank you for visiting" on it.

7. Print
  Click Print. Your browser will remember these settings (margins, headers/footers, paper size) for next time, so you generally only need to do this setup once.
